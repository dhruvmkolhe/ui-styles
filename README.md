# Chameleon UI

**Every UI Style. Authentically Crafted.**

Chameleon UI is a free, open-source gallery of **25 authentic UI design aesthetics** with **375+ copy-ready components**. Each aesthetic is a complete gallery of 15 production-ready components — rendered live in both light and dark modes. Find a look you love, copy the clean HTML + Tailwind CSS snippet, and paste it straight into your project. No accounts, no paywalls, no setup.

## What you get

- **25 design aesthetics** — Japandi, Glassmorphism, Brutalist, Minimalist, Neomorphism, Retro/Y2K, Dark Tech, Bento Grid, Neobrutalist, Swiss, Editorial, Retro Futuristic, Bauhaus, Art Deco, Material, Monochromatic, Scandinavian, Modernist, Organic, Luxury Minimal, Neo-Geo, Kinetic, Gradient Modern, Typography First, and Metropolitan.
- **15 components per style** — buttons, cards, forms, inputs, modals, tabs, tables, navigation, feedback states, loading states, charts, media, and more.
- **Light + dark modes** — every gallery flips between themes with a one-click toggle; copy the exact variant you need.
- **Copy-ready code** — clean HTML + Tailwind CSS snippets with zero dependencies. Paste anywhere, own it forever.
- **182-component catalog** — a searchable directory of every component with live previews and interactive documentation.
- **100% free** — every snippet is unwatermarked and free for commercial use. No attribution required.

## How to use it

1. **Explore styles** — browse all 25 aesthetics, each rendered live in its own visual voice.
2. **Open a gallery** — pick a style to see its full 15-component gallery.
3. **Toggle the theme** — switch between light and dark previews.
4. **Copy the code** — hit Copy on any component and paste the HTML + Tailwind into your project.

Tip: press `⌘K` (or `Ctrl+K`) anywhere to search styles and components instantly.
